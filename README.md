# Project Phantom – 3D Aerospace Simulation

Project Phantom is a personal project I built to explore 3D visualization and interactive simulation using web technologies. I wanted to create a simple aerospace-inspired environment with a modern interface and a more immersive visual experience.

The project combines a 3D scene with a futuristic dashboard, allowing users to interact with the visualization directly in their browser.

## What I Built

- A 3D environment with an aerospace-inspired design
- A dark interface with a futuristic dashboard layout
- Interactive camera controls to explore the scene
- Simulation-style controls and visual elements
- A browser-based experience without requiring a separate desktop application

## Technologies Used

- HTML
- CSS
- JavaScript
- Three.js

## Running the Project

You can run the project locally by following these steps:

1. Clone or download this repository.
2. Open the project folder.
3. Open `project_phantom.html` in Google Chrome or another modern browser.
4. Explore the 3D scene and interact with the available controls.


## About This Project

I created Project Phantom to improve my understanding of 3D visualization, web development, and interactive interface design. It gave me an opportunity to experiment with Three.js and bring together different web technologies in one project.

This is an ongoing personal project, and I plan to continue improving the interface and visual experience as I learn more.
